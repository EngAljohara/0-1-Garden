# 0/1 Garden | Arduino Smart Garden 🌱

**Digital Logic Design team project · Jubail Industrial College · 2023**

A hands-on automated plant-care prototype using an Arduino UNO and soil-moisture sensor to control watering and ventilation based on moisture readings.

## Project overview

- When soil moisture is low, the system activates a water pump.
- When soil moisture is high, the system activates a fan.
- The prototype uses an Arduino UNO, moisture sensor, relay module, pump, fan, tubing, and breadboard wiring.

## Built through independent learning

> Developed in 2023 through our own research, experimentation, debugging, and teamwork, without relying on generative AI coding assistants. This project reflects the foundational programming and electronics skills we built hands-on.

## Source code — reconstructed from presentation

The original `.ino` file is no longer available. [`arduino/SmartGarden_reconstructed.ino`](arduino/SmartGarden_reconstructed.ino) is a **reconstructed and normalized interpretation** of the Arduino code visible on slide 8 of the 2023 presentation, **not a verified original source file**. It preserves the reported low/high moisture logic but includes corrections for inconsistent declarations, output initialization, and a defined middle-range state. The code has **not been hardware-tested**; check pin assignments, relay polarity, sensor calibration, and wiring before use.
